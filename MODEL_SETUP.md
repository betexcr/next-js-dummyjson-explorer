# Model Setup

This harness is intentionally configured for:

| Role | OpenCode model |
|---|---|
| Primary autonomous builder | `opencode/big-pickle` |
| Planner | `opencode/nemotron-3-ultra-free` |
| Reviewer | `opencode/nemotron-3-ultra-free` |
| Tester | `opencode/nemotron-3-ultra-free` |

OpenCode model IDs are provider/model IDs. If the models are not available in your account, use `/models` to select an available equivalent and record the change.

Do not replace the configured IDs with display names such as `Big Pickle` or `Nemotron 3 Ultra Free`.
